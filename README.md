## 🚀 About Me

I'm a 4th-year Computer Science student from Holy Angel University (HAU) in Mabalacat, Pampanga. Inspired by my parents' strong sense of responsibility to help others, I specialize in building **AI-driven**, **cloud-integrated systems** that solve real-world problems. 

My primary focus is leveraging computer vision (CNNs, VLMs) and Natural Language Processing (NLP) for applied software development. I also have hands-on experience managing and scaling cloud-based web applications using AWS (EC2, RDS, Lambda) and setting up web environments.
